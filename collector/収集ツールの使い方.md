# ポケカ情報 収集ツール（collector）の使い方

このツールは、**公式サイトのニュースと専門メディアのRSSを自動で集めて `raw_news.json` を作る**ものです。
AIトークンは一切使いません（集めるのは「タイトル・日付・カテゴリ・リンク・情報源」まで）。
要約や初心者向け解説はAI（Claude）が担当し、**新着ぶんだけ**処理するのでトークンを節約できます。

---

## 1. 必要なもの

- **Node.js 18 以上**（インストール済み）
  - 確認方法: コマンドプロンプトで `node -v` と入力し、`v18`以上が出ればOK
- 追加のライブラリ**インストールは不要**です（Node標準機能だけで動きます）

## 2. 置き場所

```
成果物/
  index.html, style.css, app.js, news.js   ← 表示サイト本体
  raw_news.json                            ← ★ツールが作る出力（自動生成）
  collector/                               ← ★このツール一式
    collect.js
    sources.js
    package.json
    run.bat
    収集ツールの使い方.md（このファイル）
```

## 3. 実行する

**かんたん（Windows）:** `collector` フォルダの **`run.bat` をダブルクリック**。

**コマンドで:**
```
cd （collectorフォルダのパス）
node collect.js
```

実行すると、画面に取得件数が表示され、`成果物\raw_news.json` が作られます。

```
[取得] ポケモンカード公式 ... 12 件
[取得] ポケカ飯（大会・優勝デッキ） ... 10 件
[取得] 攻略大百科（ポケカ） ... 8 件
--------------------------------------
合計 28 件（うち新着 5 件）を収集
```

## 4. 更新の流れ（ハイブリッド運用）

```
① run.bat を実行            → raw_news.json が最新になる（トークン0）
② Claudeに「更新して」と頼む → 新着ぶんだけAIが要約し news.js を更新
③ index.html をリロード      → 最新ニュースが表示される
```

- ①は毎日自動でも手動でもOK。②は**見たいときだけ**でOKです（新着が無ければAIも何もしません）。
- 「要約も初心者解説も要らない、タイトルだけ見られればいい」日は、②を省いて `raw_news.json` を直接見てもOKです。

## 5. 毎日自動で収集する（任意・Windowsタスクスケジューラ）

1. スタートメニューで「タスク スケジューラ」を開く
2. 右側の「基本タスクの作成」をクリック
3. 名前: 「ポケカ情報収集」など → 次へ
4. トリガー: 「毎日」→ 時刻を指定（例: 朝7時）→ 次へ
5. 操作: 「プログラムの開始」→ 次へ
6. 設定:
   - **プログラム/スクリプト**: `node`
     （もし見つからないエラーが出る場合は、`where node` で出たフルパスを入れる）
   - **引数の追加**: `collect.js`
   - **開始（作業フォルダー）**: collector フォルダのフルパス
     （例: `C:\Users\masac\OneDrive\ドキュメント\ポケカアプリ\成果物\collector`）
7. 完了

> これで毎朝 `raw_news.json` が自動更新されます。要約（②）だけ、見たいときにClaudeへ依頼してください。

## 6. 情報源を増やす・変える

`sources.js` を編集します。RSSフィードを追加するのが簡単・確実です。

```js
{
  name: "表示名",
  type: "rss",                 // "rss" か "official-html"
  url: "https://example.com/feed/",
  reliability: 3,              // 信頼度 1〜5
  pokecaOnly: true,            // そのサイトが全部ポケカならtrue
  defaultCategory: "その他"    // カテゴリ不明時の既定
}
```

## 7. うまくいかないとき

- **「ポケモンカード公式 ... 失敗」と出る**
  公式サイト側のアクセス制限などで取得できないことがあります。その場合でもRSSの情報は集まります。
  公式が続けて失敗するようなら、Claudeに「公式が取得失敗する」と伝えてください（取得方法を調整します）。
- **`node` が見つからない**
  Node.js が未インストール、またはPATHが通っていません。`node -v` で確認してください。
- **件数が0件**
  サイト構造が変わった可能性があります。Claudeに伝えてください（パーサを直します）。

## 8. 仕組み（なぜトークンを節約できるか）

- 「情報を集める」作業は**普通のプログラム**で十分できる（タイトル・日付・リンク）。ここは無料。
- 「初心者にも分かるよう要約・解説する」作業だけがAIの仕事。これを**新着ぶんだけ**に限定することで、
  毎回ゼロからAIが巡回するより消費を大きく抑えられます。
